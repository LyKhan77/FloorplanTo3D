# M8 — Refining Setelah Tahap 5 (Human-in-the-Loop) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Pipeline berhenti di status **Perlu review** setelah tahap 5. Manusia memperbaiki spec di kanvas review 2D, dibantu daftar tugas berlokasi, alat **Tutup celah**, dan **Garis bantu** yang di-snap ke gambar asli. Setelah itu manusia menekan **Setujui & build 3D**, dan run berlanjut dari tahap 6.

**Architecture:**
- **Server.**
  - Param project `review_pause` (default `true`) membuat orchestrator menyelesaikan run dengan status `needs_review` sesudah tahap 5 sukses.
  - `POST /runs/{rid}/continue` menerima run `needs_review` tanpa `accept_low_score`, lalu memulai run baru dari tahap 6 dengan spec HEAD (yang sudah dikoreksi).
  - Dry-run `POST /specs/validate` ikut mengembalikan `rooms` (spec sesudah ops, ruang dibentuk ulang) dan `tasks` dari `core/spec/review_tasks.py`.
  - `POST /api/projects/{pid}/snap` menempelkan garis kasar (mm) ke garis ganda di `01_preprocess/bin.png` run terbaru.
- **Web.**
  - Status `needs_review` di dashboard.
  - Kanvas review 2D (`web/src/editor/review/`, SVG dalam mm) dipakai saat belum ada `shell.glb`, atau dipilih lewat mode `plan`:
    - gambar `01_preprocess/page.png` sebagai latar;
    - dinding, bukaan, dan ruang dari respons validate;
    - pilih/marquee;
    - alat `close-gap` dan `guide-line`.
  - `TasksPanel` di sisi kiri.
  - Tombol **Setujui & build 3D**: simpan dulu bila ada op, lalu `continue`.
- Semua koreksi tetap op biasa lewat `applyMany`: undo, validasi server, dan provenance `editor` tidak berubah.

**Tech Stack:** Python 3.12, FastAPI, OpenCV, Shapely; React 18 + TypeScript, Zustand, Carbon g100, SVG, Vitest; pytest.

**Spec:**
- keputusan pengguna 2026-10-29: refining setelah tahap 5, titik jeda default menyala, build boleh jalan dengan tugas tersisa sebagai warning;
- konsep yang disetujui: `temp/concept/refining-flow.html`;
- `PRD/07-web-editor.md` (editor, panel koreksi), `PRD/09-api.md` (runs, specs), `PRD/08-dashboard.md` (status);
- `benchmarks/reports/m7d-final.md` (celah pintu = penyebab kebocoran terbesar di Gatsu).

Branch: `m8-refining` dari `main`.

## Review Focus

1. **Run `needs_review` setelah server restart:** `recover()` tidak boleh menandainya `failed`, dan run tidak boleh di-queue ulang. Test di Task 1.
2. **Continue dua kali, atau continue saat masih ada op belum disimpan:**
   - server: continue kedua → 409 (run lama tidak lagi `needs_review`);
   - web: tombol menyimpan dulu, lalu continue.
   - Test di Task 1 dan Task 6.
3. **Snap di area tanpa garis ganda:** server menjawab 422 `no_line`, dan klien menampilkan notice tanpa membuat dinding. Test di Task 3 dan Task 5.
4. **Celah yang sudah memuat bukaan, atau ujung yang sudah tersambung, bukan tugas.** Test di Task 2.
5. **Gambar latar sejajar dengan spec:** transform SVG dari `grid.json["px_to_mm"]` menaruh piksel ujung sebuah dinding GT tepat di koordinat mm-nya. Test di Task 4.

### Task 2: Daftar tugas review + ruang di dry-run validate

**Files:**
- Create: `core/spec/review_tasks.py`
- Modify: `server/routes/specs.py` (`dry_run`)
- Test: `tests/spec/test_review_tasks.py`, `tests/server/test_specs.py` (atau berkas route spec yang ada)

**Interfaces:**
- Produces:
  - `review_tasks(spec: Spec, labels: list[RoomLabel] | None = None) -> list[dict]`. Tiap tugas: `{"id", "kind": "gap" | "leak" | "loose" | "type", "message", "at": [x, y], "element_ids": [...], "fix": {...}}`, diurutkan gap, leak, loose, type.
  - **`gap`:**
    - dua ujung dinding menggantung (`endpoint_connected` salah) dari dua dinding sejajar (≤ 3°);
    - jarak lateral ≤ tebal maksimum keduanya / 2 + 50 mm;
    - jarak sepanjang garis 600–1300 mm;
    - tanpa bukaan di antaranya;
    - `fix = {"a", "b", "thickness": rata-rata keduanya (dibulatkan), "kind": kind dinding pertama}`.
  - **`leak`:** ruang yang memuat label bertipe ≥ 2 (selain `other`); `at` = representative point; hanya bila `labels` diberikan.
  - **`loose`:** dinding dengan kedua ujung menggantung dan panjang < 3000 mm.
  - **`type`:** ruang `type == "other"` dengan luas ≥ 4 m².
  - **id tugas stabil:** `f"{kind}:{','.join(sorted(element_ids))}"`.
  - Respons `POST /specs/validate` sekarang `{score, passed, issues, rooms, tasks}`:
    - `rooms` = `spec.rooms` sesudah `apply` (sudah dibentuk ulang);
    - `labels` = dari `02_grid/ocr.json` run terbaru yang punya tahap 2 (`labels_from_ocr` + `crop_labels` seperti tahap 4), atau `None` bila tidak ada.

  - `test_gap_between_collinear_dangling_ends` (partisi dibelah 900 mm → satu tugas `gap` dengan `fix.a`/`fix.b` di kedua ujung);
  - `test_gap_with_an_opening_is_not_a_task`;
  - `test_connected_end_is_not_a_gap`;
  - `test_leak_needs_two_label_types`;
  - `test_loose_wall_both_ends_dangling`;

  - route: `test_validate_returns_rooms_and_tasks` (ops `delete_wall` partisi → `rooms` berkurang, `tasks` memuat jenis yang diharapkan).

### Task 3: Snap garis bantu ke garis ganda gambar

**Files:**
- Create: `core/extraction/snap.py`
- Modify: `server/routes/projects.py` (atau berkas route project) — `POST /api/projects/{pid}/snap`
- Test: `tests/extraction/test_snap.py`, test route

**Interfaces:**
- Produces:
  - `snap_wall(binary: np.ndarray, px_to_mm: list[float], a: tuple, b: tuple, search_mm: float = 400) -> dict | None`. Hasilnya `{"a", "b", "thickness"}` dalam mm, atau `None`.
    - **Profil tegak lurus:** sepanjang garis kasar, ambil sampel tiap 100 mm. Di setiap sampel ambil profil tegak lurus ±`search_mm`, lalu cari pasangan run tinta (dua muka) dengan jarak 60–400 mm yang titik tengahnya terdekat ke garis kasar.
    - **Syarat sampel:** ≥ 60 % sampel harus menemukan pasangan.
    - **Hasil:** offset dan jarak median menjadi garis tengah dan tebal (dibulatkan ke 10 mm). Ujung `a`/`b` adalah proyeksi ujung garis kasar ke garis tengah itu.
  - **`POST /api/projects/{pid}/snap`:**
    - body `{a, b}` (mm);
    - memakai `01_preprocess/bin.png` dan `02_grid/grid.json["px_to_mm"]` dari run terbaru yang punya keduanya;
    - menjawab `{a, b, thickness}`, 404 `no_run` bila tidak ada run, atau 422 `no_line` bila `None`.
