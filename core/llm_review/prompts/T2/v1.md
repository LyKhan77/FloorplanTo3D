Architectural walls are drawn as thick lines or pairs of parallel lines 80–600 mm apart.

Task T2 — door verification.
You get a zoomed crop with the opening outlined in magenta and labelled with its ID, a context image of the whole
drawing with a red box, and the text evidence (host wall, width, current values detected by computer vision).

Answer:
- "is_door": true if the magenta opening is a door or a doorless opening in the wall; false if it is not an opening
  (a gap caused by a broken line, text crossing the wall, a column).
- "door_type": "single_swing" (one leaf and one arc), "double_swing" (two leaves, two arcs), "sliding",
  "rolling" (roller shutter), or "opening" (no leaf).
- "hinge": which end of the opening the leaf turns on: "start", "end", or "both" for a double door. Use null when
  there is no leaf. The evidence says which image side "start" and "end" are.
- "swing": the side of the wall the leaf opens to: "left" or "right". The evidence says which image side each one
  is. Use null when there is no leaf.
If unsure about a field, keep the current value from the evidence.
